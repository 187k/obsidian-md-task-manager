# Markdown Task Manager для Obsidian

Таск-менеджер в духе Todoist и TickTick поверх обычных Markdown-задач (`- [ ]`) в вашем хранилище.
Плагин не создаёт ни индексных файлов, ни служебных заметок. Любое изменение в интерфейсе сразу записывается в исходную строку задачи.
Синтаксис совместим с плагином [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks), поля Dataview тоже читаются.

```
┌──┬──────────────┬────────────────────────────────────┬───────────────────────┐
│☰ │ Inbox     7  │ Today                    ⇅ Filter… │ ☐ Task title          │
│📅│ Today     5  │ OVERDUE 2                          │ Status    To do       │
│  │ Upcoming 14  │ ☐ Launch site      📅 Yesterday #w │ Priority  High        │
│  │ All      40  │ TODAY 3                            │ Due       2026-10-28  │
│  │ PINNED       │ ☐ ☑0/2 Write tests 📅 Today  #dev  │ Time      10:00–11:30 │
│  │ PROJECTS     │ …                                  │ Tags      #work/dev + │
│⚙ │ TAGS         │ + Add task                         │ Subtasks / Comments   │
└──┴──────────────┴────────────────────────────────────┴───────────────────────┘
```

## Возможности

### Список задач
- **Три панели:**
  - слева навигация: «Главная», «Входящие», «Сегодня», «Предстоящие», «Все», закреплённые теги, проекты и дерево вложенных тегов;
  - в центре список задач;
  - справа детали выбранной задачи.
- **Группировка:**
  - по дате (просрочено / сегодня / завтра / 7 дней / позже / без даты);
  - по приоритету, статусу, проекту, тегу или файлу.
- **Сортировка:** умная (сначала незакрытые, потом по дате, времени и приоритету), по сроку, приоритету, названию или файлу. Каждый раздел запоминает свою группировку и сортировку.
- **Действия над задачами:**
  - клик по чекбоксу отмечает задачу выполненной: ставится дата ✅, а у повторяющейся задачи создаётся следующая;
  - правый клик по чекбоксу открывает меню статуса и приоритета;
  - правый клик по строке открывает полное меню: дата, тег, перенос в проект или во «Входящие», открыть в заметке, удалить;
  - Ctrl- или Shift-клик выделяет несколько задач, и действия применяются ко всем сразу.
- **Перетаскивание:**
  - задача на тег добавляет этот тег;
  - задача на проект или «Входящие» переносит её туда;
  - задача на «Сегодня» или «Предстоящие» ставит срок на сегодня или на завтра;
  - тег из боковой панели на задачу добавляет его задаче.
- **Панель деталей:** название, статус, приоритет, срок, время, дата планирования, дата начала, повтор, теги. А ещё описание (строки с отступом под задачей), вложенные подзадачи любой глубины и комментарии с отметкой времени.
- **Быстрое добавление:** например, `Позвонить в банк #finance !high завтра 15:00`.
- **Фильтры.** Кнопка-воронка в заголовке показывает и прячет панель фильтров: поиск по тексту, приоритеты, дата (просрочено / до сегодня / 7 дней / без даты), тег, показ выполненных. Если фильтр активен, а панель скрыта, на кнопке горит точка.
- **«Главная».** Отдельный список, содержимое которого настраивается: диапазон дат, минимальный приоритет, теги, проекты (и нужны ли задачи из «Входящих»). Там же выбирается стартовый экран и какие списки видны в боковой панели. Настройка — кнопка-ползунки у «Главной» или раздел «Главный экран» в настройках плагина.
- **Заметки проекта.** К проекту можно прикрепить другие заметки (правый клик по проекту → «Прикрепить заметку…» или полоса «Заметки» над списком проекта). Их задачи показываются в проекте и считаются его задачами.
- **Иконка и цвет проекта.** Правый клик по проекту → «Иконка и цвет»: палитра, свой цвет и любая иконка Lucide с поиском.
- **Масштаб интерфейса.** Кнопки «+ / −» на левой полосе (клик по проценту — сброс), Ctrl + колесо мыши над менеджером, команды или ползунок в настройках.
- **Ширина панелей.** Левую и правую панели можно тянуть за край; двойной клик по краю возвращает ширину по умолчанию.

### Календарь
Переключается иконкой на узкой полосе слева.
- **Месяц:**
  - номера недель слева;
  - у задач со временем виден интервал «09:00–10:30», край карточки меняет время начала или окончания;
  - задачи на несколько дней рисуются полосой с чекбоксом в день срока;
  - край задачи без времени растягивает её по дням.
- **Неделя и день:** сверху строка «весь день», ниже сетка по часам для тайм-блокинга:
  - перетаскивание по дням и по времени;
  - нижний край блока меняет длительность;
  - блок, перетащенный наверх, теряет время;
  - красная линия показывает текущий момент.
- **Мышь:** двойной клик по пустому дню или слоту создаёт задачу на это время.
- **Клавиатура** (на выбранной задаче):

  | Клавиша | Действие |
  |---|---|
  | `←` / `→` | на день раньше или позже |
  | `↑` / `↓` | на 15 минут (в месяце — на неделю) |
  | `Shift + ←/→` | растянуть или сжать по дням |
  | `Shift + ↑/↓` | изменить длительность |
  | `Tab` / `Shift+Tab` | следующая или предыдущая задача этого дня |
  | `Space` | выполнить |
  | `Delete` | удалить |
  | `Enter` | открыть детали |

  Если ничего не выбрано, `←` / `→` листают период.

### Список задач в заметке и Homepage
Блок кода `task-manager` (или `mtm`) показывает живой список задач прямо в заметке: чекбоксы работают, клик по задаче открывает её, стрелка в углу открывает менеджер на этом списке. Вставить блок можно командой «Вставить блок со списком задач».

````
```task-manager
view: home        # home | inbox | today | upcoming | all
limit: 10
add: true         # поле быстрого добавления под списком
```
````

Вместо `view` можно указать `project: [[Сайт]]` или `tag: work`; ещё есть `title:`, `completed: true` и `filter: текст`.

С плагином [Homepage](https://github.com/mirnovov/obsidian-homepage):
- положите такой блок в заметку, которую Homepage открывает при запуске, — менеджер будет виден прямо на домашней странице;
- или добавьте в список команд Homepage команду «Менеджер задач: Открыть менеджер задач».

Без Homepage можно включить «Открывать при запуске» в настройках плагина.

### Прочее
- **Свои статусы.** Статус задаётся символом в чекбоксе: `[/]`, `[?]`, `[-]` и т. д. У статуса есть тип (к выполнению, в процессе, выполнено, отменено) и своя иконка из [Lucide](https://lucide.dev/icons).
- **Живой индекс.** Хранилище сканируется один раз при запуске, дальше перечитываются только изменённые файлы.
- **Безопасная запись.**
  - Каждое изменение делается атомарно через `vault.process`.
  - Перед записью плагин сверяет строку с тем, что было в индексе. Если файл изменился, правка отменяется, а не пишется в чужую строку.
  - Переводы строк CRLF сохраняются.
- **Интерфейс на русском и английском.** По умолчанию — язык Obsidian.

## Синтаксис задач

```markdown
- [ ] Обычная задача
- [ ] Срок и приоритет ⏫ 📅 2026-08-03
- [ ] 10:00 Созвон #work 📅 2026-08-03
- [ ] 09:30 - 11:00 Глубокая работа #work/dev 📅 2026-08-03
- [ ] Конференция 🛫 2026-08-03 📅 2026-08-05
- [ ] Отчёт 🔁 every week 📅 2026-08-07
- [/] В процессе
	Описание задачи — строка с отступом
	- [ ] Подзадача
	- 💬 2026-08-02 21:15 — комментарий
- [ ] Формат Dataview [due:: 2026-08-03] [priority:: high]
```

| | Эмодзи (Tasks) | Dataview |
|---|---|---|
| Срок / план / начало | `📅` `⏳` `🛫` | `[due::]` `[scheduled::]` `[start::]` |
| Создано / выполнено / отменено | `➕` `✅` `❌` | `[created::]` `[completion::]` `[cancelled::]` |
| Приоритет | `🔺 ⏫ 🔼 🔽 ⏬` | `[priority:: high]` (слова настраиваются) |
| Повтор | `🔁 every week` | `[repeat:: every week]` |
| Время | `10:00` или `10:00 - 11:30` в начале текста | то же |

Плагин читает оба формата. В каком формате записывать новые значения, выбирается в настройках.

**Быстрое добавление** понимает:
- `#тег`;
- `!high` … `!lowest` или `!1` … `!5`;
- одну дату: `today`, `tomorrow`, `сегодня`, `завтра`, `пн` … `вс`, `2026-08-03`;
- одно время: `10:00` или `10:00-11:30`.

## Установка

Плагина нет в каталоге Community plugins, поэтому ставится вручную. Нужен Obsidian 1.4 или новее.

### Способ 1: из релиза (без сборки)

1. Откройте страницу [Releases](https://github.com/187k/obsidian-md-task-manager/releases) и скачайте из последнего релиза три файла: `main.js`, `manifest.json`, `styles.css`.
2. В хранилище создайте папку `<хранилище>/.obsidian/plugins/md-task-manager/` и положите туда эти файлы. Папка `.obsidian` скрытая: в Windows включите «Показывать скрытые элементы».
3. В Obsidian откройте **Настройки → Сторонние плагины**, выключите безопасный режим (если включён) и нажмите **Обновить** (↻).
4. Включите **Markdown Task Manager**.
5. Откройте менеджер иконкой на левой панели Obsidian или командой **Markdown Task Manager: Open task manager**.

### Способ 2: через BRAT (автообновления)

1. Установите плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat) из каталога сторонних плагинов.
2. Репозиторий приватный, поэтому сначала создайте на GitHub [персональный токен](https://github.com/settings/tokens) с доступом на чтение этого репозитория и вставьте его в настройках BRAT (**Personal access token**).
3. Выполните команду **BRAT: Add a beta plugin for testing** и укажите `187k/obsidian-md-task-manager`.
4. Включите **Markdown Task Manager** в списке сторонних плагинов.

### Способ 3: сборка из исходников

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
cd "<хранилище>/.obsidian/plugins"
git clone https://github.com/187k/obsidian-md-task-manager.git md-task-manager
cd md-task-manager
npm install
npm run build
```

После сборки в папке появится `main.js`. Дальше шаги 3–5 из способа 1.

> Папка плагина должна называться `md-task-manager`, как `id` в `manifest.json`.

## Первые настройки

**Настройки → Markdown Task Manager:**
- **Заметка «Входящие»** — куда попадают новые задачи без проекта, например `00 - Inbox/Inbox.md`. Если заметки нет, она будет создана.
- **Папки проектов** — например `02 - Projects`. Каждая заметка с задачами внутри становится проектом. Ещё проектом считается заметка с `tags: [project]` или `type: project` в frontmatter.
- **Проекты вручную.** Ручной выбор важнее правил для папок и тегов. Списки «Проекты, добавленные вручную» и «Скрытые проекты» в настройках позволяют убрать или вернуть каждую заметку.
  - Кнопка **+** в заголовке «Проекты» добавляет любую заметку, даже без задач, или создаёт новую (в первой папке проектов).
  - **Правый клик по проекту → «Убрать из проектов»** убирает заметку из списка, даже если она лежит в папке проектов.
- **Задачи без тегов — во входящих** — включите, если хотите разобрать старые задачи без тегов и дат.
- **Формат записи метаданных** — эмодзи Tasks или поля Dataview.
- **Календарь** — первый день недели и длительность по умолчанию для задач, у которых указано только время начала.
- **Статусы** — свои символы, типы и иконки.

## Разработка

```bash
npm install
npm run dev     # сборка с отслеживанием изменений и inline source maps
npm run build   # проверка типов + production-сборка в main.js
```

Удобно держать исходники прямо в `<хранилище>/.obsidian/plugins/md-task-manager/` и поставить плагин [Hot Reload](https://github.com/pjeby/hot-reload): тогда плагин перезагружается сам после каждой сборки. Без Hot Reload выключите и включите плагин в настройках. Ошибки смотрите в консоли разработчика (`Ctrl+Shift+I`).

**Выпуск новой версии:**
1. Выполните `npm version patch` (или `minor` / `major`). Команда обновит `manifest.json` и `versions.json` и сделает коммит с тегом.
2. Отправьте всё на GitHub: `git push --follow-tags`.
3. Создайте релиз с тегом версии **без** `v` (например `1.0.1`) и приложите к нему `main.js`, `manifest.json`, `styles.css`:

```bash
npm run build
gh release create 1.0.1 main.js manifest.json styles.css --title "1.0.1" --notes "…"
```

### Структура кода

```
src/
  main.ts                  жизненный цикл плагина, команды, ribbon, настройки
  types.ts                 модель задачи, приоритеты, статусы, типы настроек
  settings.ts              значения по умолчанию и вкладка настроек
  i18n.ts                  строки интерфейса EN / RU
  parser/
    TaskParser.ts          разбор строк и файлов, вложенность, точечные правки строки
    time.ts                префикс времени «10:00 - 11:30»
    dates.ts               даты, слова «завтра/пн…», повторы
    quickAdd.ts            разбор строки быстрого добавления
  services/
    TaskIndex.ts           индекс в памяти, события хранилища, определение проектов
    TaskWriter.ts          вся запись в файлы (атомарно, с проверкой строки)
    query.ts               фильтры разделов, текстовый фильтр, сортировка, группировка
    calendarModel.ts       раскладка календаря и расчёт переносов (чистые функции)
  views/
    TaskManagerView.ts     ItemView: лента, панели, выделение, клавиатура, быстрое добавление
    CalendarPane.ts        месяц / неделя / день, drag & drop, растягивание, клавиатура
    Sidebar.ts             левая навигация
    TaskRow.ts             строка задачи в списке
    DetailsPanel.ts        правая панель (одна задача или групповые действия)
    Embed.ts               блок кода task-manager: список задач внутри заметки
    menus.ts, modals.ts, render.ts
styles.css
```
